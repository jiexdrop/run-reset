# Project rules

- Never run terminal (bash) commands unless absolutely necessary for the task.
- Prefer read-only tools (read, grep, glob) over shell commands.
- Before attempting any bash command, briefly explain what it does and ask for approval. Do not batch multiple commands to sneak them past review.
- If a task can be completed without the terminal, do not use the terminal.
- Never run commands that modify system state outside this project (installs, global config changes, deletes) without explicit user request.
